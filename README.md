# CineHub Providers

Custom provider extensions and media scrapers for the Vega / CineHub ecosystem.

This repository contains scrapers built in TypeScript and bundled into CommonJS modules for streaming media aggregation.

## Included Providers (71 Providers)
- **Bangla & Regional Hubs:**
  - CineFreak (`https://cinefreak.net`)
  - MLSBD (`https://mlsbd.co`)
  - FlixHub (`https://flixhub.net`)
  - MovieHubBD (`https://moviehubbd.net`)
  - MoviBD (`https://movibd.top`)
  - MovieBaaz (`https://moviebaaz.baby`)
  - MLX4U / Movies4U (`https://mlx4u.com`)
  - MovieLinkBD
- **Global & International Providers:**
  - Vega Movies, MoviesDrive, MultiMovies, KatMovieHD, HDHub4U, UHDMovies, 1Flex, Showbox, GokuHD, KissKH, AnimeKoto, HiAnime, Dramacool, InternetArchive, and many more.

## Development & Building

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Build all providers:**
   ```bash
   npm run build
   ```
   Compiled bundles are generated in `dist/`.

## DMCA Notice
This repository contains scraping and parsing scripts that operate like standard web browsers by retrieving publicly available information and streams from third-party websites. It does not host, control, or distribute any media files directly.
